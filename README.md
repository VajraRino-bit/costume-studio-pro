# costume-studio-pro
Multi-AI costume prompt builder with simple and advanced editing modes.
# v0.2.0 色選択拡張

詳細モードの各パーツで20色の日本語付きパレット・色見本を選択できます。
「自由に選ぶ」のカラーピッカー、またはHEXコードを入力して「適用」で任意の色を指定できます。
HEXは3桁・6桁（#省略可）に対応し、6桁の大文字に統一します。不正な値は適用されません。
「指定なし」で色指定を解除できます。色を設定していても、形状が「なし」のパーツは出力されません。

プリセットは英語の色名、カスタムカラーはHEXコードとして全出力形式に反映されます。
既存の保存形式を維持しており、配色はブラウザーの自動保存とJSON保存に含まれます。
画像生成サービスがHEXを厳密に再現するかはサービスによって異なります。
